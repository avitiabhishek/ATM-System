# ATM-System
A simple ATM simulation system that allows users to perform banking operations like withdrawal, deposit, balance check, and PIN authentication. The ATM System is a fully functional simulation of an Automated Teller Machine designed to replicate real-world banking operations.
It focuses on user authentication, transaction handling, and secure fund management, making it a strong demonstration of core programming and system design skills.

🛠️ Tech Stack
💻 Language:  Java
🧩 Interface: CLI
🗂️ Data Handling: Variables

⚙️ How It Works:
🔐 Step 1: Enter PIN  
📋 Step 2: Choose Operation  
💸 Step 3: Perform Transaction  
🔄 Step 4: Continue or Exit
